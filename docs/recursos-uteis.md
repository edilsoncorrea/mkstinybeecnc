## 🛠️ Ferramentas e Software

### Instalação de Firmware

- **FluidNC Web Installer:** https://install.fluidnc.com/
  - Instalador via navegador (recomendado)
  - Sem necessidade de downloads

- **ESP Flash Download Tool:** https://www.espressif.com/en/support/download/other-tools
  - Ferramenta oficial Espressif
  - Para Windows

- **esptool.py:** https://github.com/espressif/esptool
  - Ferramenta de linha de comando
  - Multiplataforma (Python)

### Drivers USB

- **CP210x Drivers:** https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
  - Para comunicação USB com a placa
  - Windows, Mac, Linux

### Senders/Interfaces

- **FluidNC WebUI:** (Integrada no firmware)
  - Interface web nativa
  - Acesso via Wi-Fi

- **bCNC:** https://github.com/vlachoudis/bCNC
  - Sender Python multiplataforma
  - Suporte a FluidNC
  
- **Universal Gcode Sender (UGS):** https://winder.github.io/ugs_website/
  - Java, multiplataforma
  - Suporte a GRBL/FluidNC

- **CNCjs:** https://cnc.js.org/
  - Interface web moderna
  - Node.js

- **OpenBuilds CONTROL:** https://software.openbuilds.com/
  - Interface amigável
  - Windows/Mac

### CAM Software

- **Fusion 360:** https://www.autodesk.com/products/fusion-360/
  - CAD/CAM completo
  - Versão gratuita para hobby

- **FreeCAD + Path Workbench:** https://www.freecad.org/
  - Open source
  - CAM integrado

- **Carbide Create:** https://carbide3d.com/carbidecreate/
  - Gratuito
  - Simples de usar

- **EstlCAM:** https://www.estlcam.de/
  - Pago, mas barato
  - Ótimo para iniciantes

- **VCarve/Aspire:** https://www.vectric.com/
  - Profissional
  - Pago

### Simuladores G-Code

- **CAMotics:** https://camotics.org/
  - Open source
  - Simulação 3D

- **NCViewer:** https://ncviewer.com/
  - Online
  - Gratuito

- **G-Code Q'n'dirty toolpath simulator:** https://nraynaud.github.io/webgcode/
  - Online
  - Rápido

### Validadores e Utilitários

- **YAML Lint:** https://www.yamllint.com/
  - Validador de sintaxe YAML
  - Online

- **G-Code Beautifier:** https://www.camotics.org/gcode.html
  - Formata e limpa G-code

- **Steps Calculator:** https://blog.prusaprinters.org/calculator_3416/
  - Calculadora de steps_per_mm

## 🆘 Suporte

### Onde Pedir Ajuda

1. **Discord FluidNC** (Mais rápido)
2. **GitHub Discussions** (Melhor para documentação)
3. **Reddit r/hobbycnc** (Comunidade amigável)
4. **Este repositório** (Issues para documentação)

### Como Pedir Ajuda

Sempre inclua:
- Versão do FluidNC (`$I`)
- Config.yaml (se relevante)
- Mensagem de erro completa
- Fotos/vídeos do problema
- O que já tentou
